TBR Examples
============

These executable examples demonstrate complete Time-Based Regression workflows.
They use reproducible synthetic data so that the simulated treatment effect is
known; an effect is not known when analyzing real experimental data.

Start with ``plot_basic_analysis.py`` for the complete workflow, continue with
``plot_incremental_analysis.py`` to examine cumulative and subinterval effects,
and then use ``plot_method_chaining.py`` for fluent API patterns.

TBR is domain-agnostic, but its assumptions must be assessed for each
application. See the :doc:`Quick Start </api/quickstart>`,
:doc:`Common Patterns </api/patterns>`, and
:doc:`Mathematical Methodology </mathematical_methodology>` for data
requirements, usage guidance, and statistical assumptions.
